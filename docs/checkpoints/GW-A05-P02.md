## Implemented

- New independent `ghostwire_protocol` library / alias `GhostWire::protocol`,
  with only header-only value-contract dependency. No reverse links to identity.
- Concrete bounded C++20 strict CBOR v1.0 frame encoder/decoder, four-byte
  network-order prefix and strict no-trailing-bytes rule. Only kinds 1, 2, 10.
- Immutable-to-caller decoded values; fixed-size offer/selection values;
  optional transient routing token; opaque public A04 record bytes preserved.
- Explicit `Admission` concurrency slot with RAII lease, cooperative stop,
  deadline and tighter byte/work budget; fixed error code without raw content.
- Pure `selected_was_offered()` advisory helper; it never authenticates a peer
  or authorizes a capability.
- Frozen pre-existing A05-P01 exact-byte and rejection tests, A04 signed record
  integration test, constrained randomized input mutations, Clang libFuzzer with ASan/UBSan (20,000 runs), and a test-only
  independent Python CBOR AST/schema fixture check. Optional libFuzzer entrypoint.
- Source boundary checker extended to enforce the new module boundary.
