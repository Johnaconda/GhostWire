## Security review finding

- Maximum frame body: 65536 bytes; public DeviceSet: 182–1718 bytes. The
  restricted nonrecursive parser charges token work and byte copying, checks
  stop/deadline at admission and during parse and before result return, and
  returns errors with fixed codes, not incoming content. Allocation and failure
  atomicity were exercised with test-only hooks; source code reviewed.
- No network-source parser audit, formal proof, concurrent data-race audit,
  full memory-exhaustion simulation or independently maintained CBOR library
  comparison is claimed. Actual pinned TinyCBOR v7.0 source still cannot be
  downloaded/compiled here because codeload.github.com DNS is inaccessible.
- A05 security gate **remains blocked**; A06 networking, persistence, auth,
  discovery, GUI and future protocol kinds are not authorized by this patch.
- Windows Defender earlier reported a severe detection on the older HF01 ZIP;
  source hashes cannot adjudicate that finding. No new policy bypass commands.
